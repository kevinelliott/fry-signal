# First shift surface

## Scope and mode

- Scope: the complete walletless `Midnight Merge` gray-box-to-playable vertical.
- Mode: Operate.
- Audience: a first-time player on mobile or desktop who must understand that their job is shaping flow, not cooking faster.
- Task: see the wave, commit a batch posture, throw route switches, recover a wrong turn, and settle the shift.

## Product and interaction contract

- Core playable verbs are `read -> commit -> switch -> recover`.
- Batching, ordinary packing, and dispatch mostly visualize consequences. Manual packout appears only for exceptions and recovery.
- The route board and active bottleneck remain visible on mobile; contextual sheets must not turn play into five hidden task pages.
- No wallet, token, network request, public rank, recovery multiplier, or money-first HUD appears.
- A deliberate fault can never improve score, health, progression, or future eligibility.

## Chosen direction

The roadside signal desk: a cheerful 1960s drive-through control room expressed as a late-night electromechanical routing instrument. The approved north star is `.impeccable/mocks/fry-signal-b-approved.png`.

The durable composition is a road forecast at left, a dominant side-on route network in the center, and an exception/dispatch rail at right. The memorable moment is the Light Run: ghost-pulse preview, physical gate flip, bag travel, taillight clear, then BATCH/PACK/GO answering on the Mile 42 marquee.

## Comp inventory and implementation medium

| Visible ingredient | Commitment | Medium |
|---|---|---|
| Mile 42 marquee | Fixed BATCH/PACK/GO positions with shape, pattern, label, and lamp count | Semantic HTML/CSS plus authored SVG icons |
| Road forecast | Three announced waves, ranges, order silhouettes, and next decision | Semantic HTML/CSS; no raster text |
| Dominant routing board | Four source tracks, two windows, physical gates, selected path, Loopback Save, Rescue Spur | Semantic HTML + responsive CSS/SVG route geometry |
| Traveling bags | Order identity and current route remain visible; motion follows the actual path | CSS offset-path where available with a discrete reduced-motion fallback |
| Dispatch rail | Exceptions and consequences only; no routine bag-by-bag minigame | Semantic HTML/CSS |
| Service strip | Warmth, accuracy, flow, and crew condition before House Book economics | Semantic HTML/CSS; exact causal copy |
| Enamel and metal depth | Sun-faded cream, asphalt, galvanized edges, physical switches | CSS surfaces and restrained shadows; no decorative glassmorphism |
| Pixel vehicles and food shapes | Countable, accessible silhouettes; never color-only | Authored SVG icons or CSS geometry with text labels |

## Responsive contract

- Desktop: asymmetric forecast / board / exception rail.
- Tablet: forecast and board remain visible; exception rail becomes an anchored sheet outside the active gate.
- Mobile: vertical route board stays continuously visible with one contextual action rail; forecast collapses to the next announced decision and wave drawer.
- All essential routes remain operable without drag at 320px, keyboard-only, touch, 200% zoom, reduced motion, and forced colors.

## Non-literal comp elements

- Remove routine HOLD/LOOP/SEND buttons from every bag; show actions only for the selected exception.
- Remove recovery as a positive score category.
- Do not represent crew as capacity counters or collectible upgrades.
- Do not use a mascot panel in the live HUD.
- Replace traffic-light color semantics with stable shape, pattern, position, and accessible names.

## Open decisions

- Multi-device/server persistence begins only when shared accounts enter scope.
- Any scarce or transferable eligibility requires separate server-verified replay and cannot inherit a client-only result.
- The first Tezos proof, if approved after the game proves fun, is one Signal Fixture flow; all other asset classes remain deferred.
